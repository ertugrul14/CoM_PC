# Gong et al. (2023) — CPPM Parking + Street-View GCN-GRU

**Full citation:** Gong, S., Qin, J., Xu, H., Cao, R., Liu, Y., Jing, C., Hao, Y., & Yang, Y. (2023).
Spatio-temporal parking occupancy forecasting integrating parking sensing records and street-level images.
*International Journal of Applied Earth Observation and Geoinformation*, 118, 103290.

## What they did
- CPPM model: GCN + GRU + CNN (street-view image similarity) + Bayesian probabilities
- Three adjacency matrices combined: distance (Manhattan), street-view similarity (ResNet50 cosine), activity-type similarity (POI cosine)
- Two case studies: Ningbo (44 parking lots) and Beijing (101 parking lots)
- 15-min time bins; weekday vs weekend split

## Key findings
- CPPM outperforms GRU-only and T-GCN baselines on both cities
- Best parameters: distance matrix weight α=1, image similarity β=0.625, POI weight γ=0 (POI similarity NOT useful)
- Maximum Search Radius (MSR): infinity on weekdays (full graph), 800m on weekends
- Weekday prediction easier than weekend (more regular commuter patterns)
- Activity type similarity around parking lots does NOT correlate with private car movement
- Street-view similarity: Ningbo shows more variance than Beijing (more green vegetation in Ningbo)

## How this supports the thesis
- Confirms GRU over LSTM for temporal component (efficiency + comparable accuracy)
- Validates POI features in spatial graph (but warns γ=0 for activity type → inform feature ablation)
- Validates 15-min time bins for parking occupancy
- Bayesian adjacency matrix formulation: reference for our Gaussian kernel spatial graph
- Weekday/weekend split justification for separate cluster archetype analysis

## Key numbers to cite
- CPPM R² = 0.957 weekdays, 0.902 weekends (Ningbo)
- GRU-only R² = 0.877/0.846 → CPPM improvement ~9% weekdays, ~7% weekends
- POI weight γ=0 best → "activity type similarity does not predict car movement" (cite in feature importance)
