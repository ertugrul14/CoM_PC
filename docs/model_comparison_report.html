Three-Way Model Comparison

Curbside Intensification · dual-head MultiGCN (1,397 streets × 14,400 bins, 68,076 params) · old production model vs. the ablation study vs. the foundation-fixed retrain · 4 June 2026.

This document compares three things: (1) the previous production model, (2) the ablation experiments that probed how the model should be trained/evaluated, and (3) the latest model after the data-foundation fixes. Read the headline table together with the warning beneath it — two of the rows are measured on a different street population and must not be compared with the others.

The one rule for reading this table

The 4.454 (new, all-street) and 22.84 (Exp B, sensor-only) measure different street populations. The all-street average is dominated by the ~1,323 easy, imputed streets; the sensor-only average reflects only streets with ground truth. "22.8 → 4.45" is not a valid improvement. The only fair head-to-head here is row 1 vs row 3 (old vs new, both all-street): 5.535 → 4.454, a 19.5% error reduction. The new model's sensor-only figure — the one directly comparable to the ablation rows — has not yet been measured.

2. The old model (baseline production)

The previous dual-head MultiGCN. Pedestrian loss was trained across all 1,397 streets on a single global normalisation, with weather merged 11 hours out of sync and sensor outages filled with zeros. It reported a strong-looking all-street test MAE of 5.535 — but the ablation below showed that figure is flattered by the imputed streets.

3. The ablation study (how should we train & evaluate?)

All three ablation conditions were scored on the 74 sensor streets only — the honest test set — to ask whether the imputed network and loss-masking actually help accuracy where we can verify it.

ConditionWhat it didMAEVerdict
BaselineOld model re-scored on the 74 sensor streets30.72 The "true" accuracy on real streets — 5.5× worse than its all-street 5.5
Exp ADeleted the 1,323 unsensored streets; trained the 74-node subgraph 22.34Better — but 35 of 74 nodes became isolated (network fragmented)
Exp BKept all 1,397 as context; pedestrian loss computed only on the 74 22.84Comparable to A; preserves the network

What the ablation taught us

  • Report accuracy disaggregated. The same model scores 5.5 across all streets but 30.7 on the streets with ground truth — a 5.5× gap. The all-street number alone is misleading.
  • Honest (masked) treatment of the target gives a truer, better sensor-street number (~22 vs 30.7).
  • The unsensored streets are needed for connectivity. Removing them isolated 35 of 74 sensor nodes — their neighbours were the unsensored streets. Imputation earns its place as network connective tissue, independent of any accuracy claim.

Limits of the ablation

Single random seed; Exp A and B used different normalisation (a confound); Exp B was under-trained. So A (22.34) vs B (22.84) is within noise — it does not prove "subgraph beats full graph." Only the three lessons above are robust.

4. The new model — what changed, and why it is better

A stress-test found five data-foundation defects; all were fixed before this retrain (detail in docs/notes/decisions.md, D-011→D-015):

Weather timezone (was 11 h out)Weather now aligned to local activity — should turn a harmful feature into a useful one

Why the gain is genuine — and understated

  • The outage mask removes easy "predict 0" wins, which should raise error — yet error still fell ~20%. The log1p conditioning gain outweighed that headwind, so the real improvement is larger than 19.5%.
  • R² rose alongside MAE (0.890 → 0.911). R² is scale-relative and barely affected by the changed evaluation denominator, so it confirms a real gain rather than a metric artefact.
  • Parking unchanged — the parking pathway was untouched; clean convergence, no instability.

5. Bottom line & open item

  • Fair, proven result: the foundation fixes improved the all-street model from 5.535 → 4.454 MAE (−19.5%) and R² 0.890 → 0.911 over the old model.
  • Established separately by the ablation: evaluation must be disaggregated; the imputed network is required for connectivity; honest (masked) targets give truer sensor-street accuracy.
  • Still open: the new model's sensor-only MAE — the figure directly comparable to Exp A/B (22–30) — has not yet been measured. Until it is, no claim should be made that the new model beats the ablation conditions on real streets.
