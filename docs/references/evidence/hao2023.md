# Hao et al. (2023) — MultiGCN-LSTM Curb Management

**Full citation:** Hao, H., Wang, Y., Du, L., & Chen, S. (2023). Enabling smart curb management
with spatiotemporal deep learning. *Computers, Environment and Urban Systems*, 99, 101914.

## What they did
- MultiGCN-LSTM model jointly predicting pedestrian flow AND parking occupancy
- Dual graph: spatial (k-NN distance) + semantic (land-use cosine similarity)
- Study area: unspecified US CBD, street-segment level
- Scenario simulations: PUDO zones, parking towers, flex-use curb

## Key findings
- Dual-graph outperforms single-graph significantly:
  - Removing semantic GCN → RMSE increases ~3.5× (Table 3–4)
  - Removing spatial GCN → RMSE increases ~1.8×
- Joint prediction (ped + parking together) outperforms separate models
- Scenario simulations show parking reduction → pedestrian flow increase in flex windows
- Flexibility windows (high ped demand + low parking) are identifiable in advance

## How this supports the thesis
- **Primary architectural blueprint**: dual-graph GCN + temporal encoder
- Justifies semantic graph (mutual cosine similarity on land-use features)
- Justifies joint prediction instead of separate ped/parking models
- Scenario simulation methodology adopted directly (flex windows, 25/50/75% reduction)
- Ablation study design adopted (remove each branch, report RMSE delta)

## Key numbers to cite
- Semantic GCN removal → RMSE ×3.5 (cite when justifying semantic branch)
- Flexibility window coverage: % of weekly hours per cluster archetype

## Limitations they note
- Single city, no cross-city generalisation test
- LSTM used (we use GRU — lighter, comparable accuracy)
